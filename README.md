## 💻 Sessions Code

The following programs and practice exercises are included in this repository:

### 📌 Programs

1. **Palindrome Number**

   * Check whether a given number is a palindrome.

2. **Armstrong Number**

   * Check whether a given number is an Armstrong number.

3. **Cube Sum of N Natural Numbers**

   * Calculate the sum of cubes of the first `N` natural numbers.

4. **Pattern Program – Increasing Numbers**

   * Print a pattern of **5 rows**, with numbers increasing from `1` to `5`.

   **Example:**

   ```text
   1
   12
   123
   1234
   12345
   ```

5. **Pattern Program – Decreasing Numbers**

   * Print a pattern of **5 rows**, with numbers decreasing from `5` to `1`.

   **Example:**

   ```text
   54321
   5432
   543
   54
   5
   ```
